# Aim Companion 1.0.7

This release corrects the Microshot Speed warm-up launch name.

## What changed

- The Valorant and Counter-Strike warm-up now requests the exact scenario name `Microshot Speed`.
- Existing saved recommendations using `MicroshotSpeed` are translated automatically.
- Steam deep links preserve the required space as `Microshot%20Speed`.

Existing scores, settings, routines, and training history are preserved during installation.
This build is not Authenticode-signed; use the matching `.sha256` asset to verify
installer integrity.
